## Projeto Máquina Vendas CSI-22

Este projeto corresponde à atividade avaliativa da disciplina CSI-22 (Programação  Orientada a Objetos) do Instituto Tecnológico de Aeronáutica (ITA). O exame consiste na implementação de um projeto-brinquedo em linguagem Python referente a uma máquina de vendas. O objetivo dessa atividade é praticar conceitos de POO e de boas práticas de implementação de projeto.

## Instruções

O projeto foi implementado utilizando-se a versão 3.14.3 do Python. Certifique-se de ter essa versão instalada em sua máquina.

Clone o projeto em uma pasta com ```git clone```. Na mesma pasta, execute no terminal:

```python
python -m main.py
```

Utilize a máquina de vendas conforme as orientações do terminal e aproveite as bebidas!
